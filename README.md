# SmashUltimateInfoGenerator
A tool to generate info.toml files for Smash Ultimate mods.

## Dependencies:
Automatic mod download + extraction:
- 7Zip or WinRAR for extracting .rar files
Sync mods/arcropolis cache with Switch:
- FTP homebrew app for Switch (mtheall/ftpd)

## Quick Start:
- You can either setup manually or use the exe build for windows

## Setup 

### Manual Setup:
1. Install Python 3.10+ and add to PATH
2. Install 7Zip or WinRAR
3. Install FTP homebrew app for Switch (mtheall/ftpd)
4. Make a virtual environment and activate it
```sh
python -m venv .venv
.\.venv\Scripts\activate
```
5. Install requirements
```sh
pip install -r ./requirements.txt
```
6. Run main.py file (Run main.exe for exe build)

### How to build EXE:
Run setup.py
```sh
python setup.py build
```

### System Requirements for Archive Extraction
The application supports extracting ZIP, 7z, and RAR archives:
- **ZIP and 7z files**: No additional software needed (uses native Python libraries)
- **RAR files**: Requires [7-Zip](https://www.7-zip.org/) to be installed
  - Download and install 7-Zip from https://www.7-zip.org/
  - The application will automatically detect and use it for RAR extraction

## How to use
1. Install python and add to path
2. Open cmd
3. pip install -r .\requirements.txt
4. Run main.py file (Run main.exe for exe build)
```sh
python main.py
```
5. Load the directory of the mod file with files like fighter, sound, effect, ui, etc.
6. Enter the gamebanana url if you want authors and accurate mod name, otherwise authors have to be entered in manually and the folder name will be trimmed to get the mod name.
7. Add an image by clicking 'Browse' under 'Image'.
8. Make changes if necessary and click apply.

## Features
* Generate `info.toml` for mods by scanning mod folder
* Search/download mods and thumbnails from gamebanana
* Install mods (folder/.zip/.7z/.rar) with drag and drop
* Batch generate `info.toml` files
* Toggle mods on/off
* Sync mods with physical switch via FTP server
* Export mods to folder
* Workspace management
* Supports slots for fighters and stages

## Platform
* Windows (EXE build)
* Linux (Tested on Ubuntu 22.04 LTS)

* character_names.csv contains all the names of the characters. I don't recommend changing the key column due to the fact that the script uses that value to see which characters are present. You are free to change the custom and group columns(The values that actually show up in the display_name).
